# Phoenix для Linux

Десктопная версия Phoenix: то же ядро логики (сбор конфигов, проверка серверов и сервисов, рейтинг), окно на Compose Desktop
и подключение через Xray + системный прокси. Протестирована логика; окно собрано и проверено только на синтаксис, так что
первая сборка может потребовать правок.

## Запуск из исходников

```bash
cd desktop
../gradlew run
```

Нужен JDK 17. При первом запуске откройте «Настройки» → «Установить ядро»: приложение скачает Xray-core с GitHub
(XTLS/Xray-core, `Xray-linux-64.zip`), сверит SHA-256 из файла `.dgst` и положит его в `~/.local/share/phoenix/xray`.
Системный `xray` из PATH тоже подойдёт.

## Пакет .deb

```bash
cd desktop
../gradlew packageDeb
sudo apt install ./build/compose/binaries/main/deb/phoenix_*.deb
```

## Как работает

* **Сбор и проверка** — те же файлы, что в Android-версии (`tools/kt-harness/pure.txt`), копируются в `desktop/build/shared` при сборке.
* **Проверка серверов** — для каждого сервера поднимается временный процесс Xray с SOCKS на localhost (с паролем), через него идут запросы.
  Один процесс обслуживает все проверки сервера и закрывается через 20 секунд простоя.
* **Подключение** — Xray со входами SOCKS `127.0.0.1:10808` и HTTP `127.0.0.1:10809`; включается системный прокси через `gsettings`
  (Cinnamon, GNOME, MATE), при отключении возвращаются прежние значения. Если сервер перестал отвечать, приложение само берёт следующий.
* **Без окна**: `phoenix --collect` — сбор и проверка, затем выход (для cron / systemd-таймера). `--minimized` — сразу в трей.

## Чего нет по сравнению с Android

Обхода VPN для отдельных приложений, режима «по открытию приложения», плитки и виджета, TUN-режима «весь трафик системы»
(на Linux он требует прав root; пока работает системный прокси — приложения, которые его не читают, нужно настроить вручную
на SOCKS/HTTP выше).

## Проверка логики

```bash
bash desktop/tools/check.sh     # компиляция и тесты без Gradle; настоящее ядро: PHOENIX_TEST_XRAY=~/.local/share/phoenix/xray/xray
```
