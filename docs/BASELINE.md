# Базовые данные (что накоплено на практике)

Источник: журнал реального использования с мобильной сетью (22.10–10.11.2026). Файл `app/src/main/assets/baseline_sources.tsv`:
по каждому источнику число удачных загрузок, сбоев и среднее число конфигов.

## Проверка сервисов через серверы (доля удачных проверок)
| Сервис | Белые списки | Чёрные списки |
|---|---|---|
| Telegram | 80 % | 93 % |
| Qwen | 75 % | 92 % |
| Steam | 71 % | 91 % |
| YouTube | 64 % | 91 % |
| Gemini | 57 % | 64 % |
| Claude | 53 % | 82 % |
| NotebookLM (чёрные) | — | 87 % |

Вывод: в белых списках Claude и Gemini закрыты примерно через каждый второй сервер, поэтому приложению нужна проверка именно этих сервисов, а не «любой рабочий».

## Источники
Самые стабильные (≥ 80 % удачных загрузок) и объёмные: AetrisVPN, whoahaow/rjsxrd, vladvarp/Prometheus, sub.vlessfo.ru, etoneya.su, zieng2/wl vless_lite, StekloVPN, vpn.akres.fun, GooseVPN (balanced/plus), igareck BLACK_*, FLAT447.
Нестабильные или малоконфигные: LimeVPN (0 удачных загрузок из 5), несколько списков на gitverse (в среднем до 20 конфигов), eavevpn, subrostunnel, Diversan313/apex-parser (около 70 %).
Полная таблица — в `baseline_sources.tsv`.

## Чего здесь нет намеренно
- Отдельных серверов: списки меняются ежедневно, старые адреса к моменту выхода релиза мертвы.
- Рейтингов стран: выборка слишком шумная и привязана к одному оператору.
- Личных подписок и токенов.
